# Model calibration log

Dated per-role evidence from parallel two-tier A/B passes (and in-anger
observational runs) of the subagent model assignment in
[`workflow.md`](workflow.md) §"Model assignment".

**These entries are evidence, not standing rules.** Each records what a
specific model pair did on a specific artifact on a specific date. The
prescriptive output — the tier for each role, and the criteria for flagging a
coder slice to the higher tier — lives in `workflow.md`; this file is why.

Two caveats when reading:

- **The tier names are aliases and they float.** Every entry below predates
  the current model generation, so "Sonnet" and "Opus" here name whatever the
  aliases resolved to in April 2026 — not what they resolve to today. Treat a
  per-model observation as a data point with an expiry, not a trait.
- **Re-run rather than extrapolate.** `workflow.md` §Calibration specifies the
  protocol (parallel A/B on the same artifact, compare critiques). When a tier
  decision matters, run it against the current aliases and append the result
  here.
