# M6.I — Texel tuning harness (plan)

Tune the ~193 linear deferred eval-term weights (M6.B–F, minus the deferred
king-safety S-curve) against the frozen 8M-position corpus, gated by a mixed-TC
SPRT vs `M6.F`. Design + rationale: **ADR-0037**. Research:
`m6.i-texel-corpus-depth.md`, `texel-position-sampling.md`, `m6-texel-tuning.md`.
This plan is signatures + tests + order + parallelization.

## Scope and non-goals

- **In:** `src/texel/` library + `src/bin/texel-tune.rs`; the parameterized
  `reference_score_white` oracle + the fast cached feature model; Adam + closed-form
  gradient; K-fit; `bench/m6-params.json` + sensitivity table; `apply` codegen;
  R1/R3/R6/R7 robustness; tests.
- **Out (operator-gated, the M6.G precedent):** the ~10h mixed-TC SPRT vs `M6.F`
  and the verdict-ladder land/revert decision (ADR-0037 §9). The harness + a tuned
  `bench/m6-params.json` (from the in-session full tune) are delivered. (Verdict-4
  "revert" = the `M6.F` shipped state — deferred terms stay zeroed; no literature
  values are ever written to `eval/data.rs`.)
- **Deferred / excluded:** king-safety **S-curve table + 4 attacker-multipliers**
  (quiet-corpus blind spot — ADR-0037 §3; frozen at shipped=zero); Arm B PST
  co-tune; joint gradient over the scale numerators (coarse outer sweep only).
- **Frozen reference frame:** material, 12 PSTs, bishop-pair, mop-up,
  `EG_SCALE_DEN`, `FIFTY_MOVE_TAPER_FROM`, `PASSED_KDIST_CAP`.

## Unit-sizing justification

Larger than the workflow's ~500-line target, kept as **one unit** because the
correctness story is indivisible: the `layout`/`EvalParams` contract, the
`reference_score_white` oracle, the fast model, and `apply` all share one
parameter vector, and the load-bearing three-tier cross-check spans them. Cutting
mid-contract would fragment that. Two scope reductions keep it bounded: the
king-safety S-curve is excluded (above), and **mixture meta-optimization is an
optional secondary subcommand, not the default tune path** (ADR-0037 §8 — the
research rates source-mix second-order). Implemented as sequential commits along
the parallelization seams below; reviewed as one design.

## Engine-neutrality invariant (landing gate)

Two kinds of `eval/` edits, both `evaluate`-neutral:
1. **Comment-only** markers (`// TEXEL-TUNABLE-BEGIN/END: <group>`) around the
   tunable `eval::data` const blocks (for `apply`).
2. **Additive read-only `pub(crate)` feature accessors** in `eval/mobility.rs`,
   `eval/king_safety.rs`, `eval/tier1.rs`, `eval/pawns.rs` that share detection
   code with the existing scoring functions (the scoring fn is refactored to / pinned
   equal to `dot(features, shipped_weights)`). **Not called by `evaluate`** ⇒
   `evaluate` byte-identical to `M6.F` ⇒ bench `1213649` / d4 `90591` byte-for-byte
   (the M6.G `quiescence_eval_white` read-only-seam precedent). The deterministic
   bench is the neutrality gate (no SPRT for the harness landing). A
   `cargo test` + `bench` byte-check confirms the refactor preserved every term value.

## Canonical param layout (`texel::layout`, shared contract — pin first)

- `const N_CORE: usize` — flat linear-core tunable count (~193).
- `enum Group { IsoDblBwd, Conn, Passed, MobN, MobB, MobR, MobQ, KsShieldFile, Outpost, RookFile }`
  + `fn group_range(Group) -> Range<usize>`.
- **Excluded from the core vector** (frozen at shipped): king-safety S-curve table,
  4 attacker-multipliers. **Outer-swept (not in core vector):** 3 scale numerators.
  Both live in `EvalParams` as separate fields, held at `shipped()`.

## Signatures

### `params.rs`
```rust
pub struct EvalParams { /* the FULL eval weight set as runtime fields, mirroring eval::data */ }
impl EvalParams {
    pub fn shipped() -> Self;                  // read from eval::data (single source of truth)
    pub fn core_to_vec(&self) -> Vec<f64>;     // flat linear-core view (layout order)
    pub fn with_core(&self, v: &[f64]) -> Self; // replace core fields; non-core = self
    pub fn to_ints(&self) -> EvalParamsI32;    // integer-quantized for apply/reference scoring
}
#[derive(Serialize, Deserialize)]
pub struct ParamsFile {                         // bench/m6-params.json
    pub schema_version: u32, pub params: EvalParamsI32, pub k: f64, pub mix: [f64; 4],
    pub stopping: StoppingConfig, pub sensitivity: Vec<ParamSensitivity>,
    pub lane_sha256: [String; 4], pub seed: u64,
}
pub fn read_params_file(p: &Path) -> Result<ParamsFile, TexelError>;  // reject on schema mismatch
pub fn apply_to_data_rs(p: &EvalParamsI32, data_rs: &Path) -> Result<(), TexelError>; // marker regions
```
CONN is the one **live** group in `shipped()` (non-zero); ISO/DBL/BWD/passed/mobility/
king-safety/outpost/rook = 0. `apply` rewrites every tunable region incl. CONN.

### `features.rs`
```rust
pub fn reference_score_white(pos: &Position, p: &EvalParams) -> i32; // full evaluate_core re-impl (oracle)
pub struct FeatureVec {            // identity scale; raw counts (NOT phase-folded)
    pub base_mg: f32, pub base_eg: f32, pub mop_up: f32, pub phase: u8,
    pub coeffs: Vec<(u16, f32)>,   // (core index, raw count); MG/EG parity fixed by layout
}
pub fn extract(pos: &Position) -> FeatureVec;
pub fn model_score_white(fv: &FeatureVec, core_w: &[f64]) -> f64;
```
`model_score_white` mirrors `evaluate_core`'s **single** blend division — accumulate
two f64 sums, divide by 24 once (NOT per-term, which would drift several cp):
`mg = base_mg + Σ_{k∈MG} w·count`; `eg = base_eg + Σ_{k∈EG} w·count`;
`score = (mg·phase + eg·(24−phase))/24 + mop_up`. `base_mg/base_eg/mop_up` = frozen
contribution (material + PST + bishop-pair + mop-up). The reference scorer (not the
fast model) applies the endgame-scale + mop-up-after-scale split — the outer-sweep path.
`EvalParamsI32` = field-for-field integer mirror of `EvalParams` (round the core, carry
non-core fields from `shipped()`); it is the serialized + `apply` artifact.

### `dataset.rs`
```rust
pub struct LaneSet { pub recs: [Vec<CorpusRecord>; 4], pub sha256: [String; 4] }
pub fn load_lanes(dirs: [&Path; 4]) -> Result<LaneSet, TexelError>;  // store::scan_valid_blocks + read_manifest
pub fn build_cache(lanes: &LaneSet, out: &Path, workers: usize) -> Result<CacheMeta, TexelError>; // parallel extract
pub fn stream_chunks(cache: &Path, chunk: usize) -> impl Iterator<Item = Vec<CachedRec>>; // bounded mem (R6)
pub struct Split { pub train: Vec<u32>, pub val: Vec<u32> }
pub fn split_by_game(meta: &CacheMeta, val_fraction: f64, seed: u64) -> Split; // group-by-game, no leakage
```
`CachedRec`: `{ base: f32, coeffs: Box<[(u16,f32)]>, label: u8, source: u8, strata: u8, depth_rung: u8, game_id: u64 }`.
Cache = header (`N`, layout-hash, lane sha256s) + length-framed records, sorted `(source, game_id, ply)` (deterministic).
**R7:** the per-chunk gradient is a rayon parallel reduce; the chunk *stream* is sequential (bounded memory).

### `loss.rs`
```rust
pub struct Reg { pub l2_lambda: f64, pub init: Vec<f64>, pub mono_lambda: f64 } // init = shipped core vec
pub fn loss_and_grad(chunk: &[CachedRec], w: &[f64], k: f64, reg: &Reg, grad: &mut [f64]) -> (f64, usize);
pub fn fit_k_features(cache: &Path, w: &[f64]) -> f64; // golden-section via a feature-backed score closure
```
Gradient: `∂L/∂wₖ += 2(σ−label)·σ(1−σ)·K·featₖ` + `2·l2_lambda·(wₖ−initₖ)` + monotonicity-penalty grad on table groups.

### `optimizer.rs`
```rust
pub struct Checkpoint { pub w: Vec<f64>, pub best_w: Vec<f64>, pub m: Vec<f64>, pub v: Vec<f64>,
    pub iter: u64, pub k: f64, pub rng: u64, pub patience: u32, pub val_hist: Vec<f64> }
pub fn save_checkpoint(c: &Checkpoint, path: &Path) -> Result<(), TexelError>; // temp→fsync→rename (R1)
pub fn load_checkpoint(path: &Path) -> Result<Checkpoint, TexelError>;          // ignores torn temp

pub fn tune(cache: &Path, split: &Split, init: &EvalParams, cfg: &TuneConfig,

```

## Test coverage (written + reviewed before implementation)

**`features.rs` — the load-bearing correctness surface (ADR-0037 §7), three tiers:**
- `reference_matches_static_eval_at_shipped` — ≥2000 corpus FENs + hand-built EP / promotion / castling-rights fixtures: `reference_score_white(pos, shipped()) == quiet::static_eval_white(pos)` exactly (≤1cp).
- `model_matches_reference_at_random_and_literature_weights` — over the battery at random + literature-magnitude core `w`: `model_score_white(extract(pos), w) ≈ reference_score_white(pos, shipped().with_core(w))` ≤2cp. **Catches feature-count / phase-fold bugs in the tuned regime** (the tautology the shipped-only check misses).
- `reference_scale_matches_eval_at_boundary_fixtures` — OCB-with-pawns / pawnless-drawish / `hmc∈{80,81,100}` fixtures with non-identity scale numerators: reference reproduces `evaluate`'s `blended·scale/DEN + mop_up`.
- `model_division_order_matches_evaluate_core` — model uses one blend division (two summed f64s ÷ 24), pinned against a hand-computed `(mg·phase+eg·(24−phase))/24` on a multi-term position (catches per-term-division drift).
- `score_is_linear_in_core_weights` — property: `model_score(a·w+b·u) == a·(model−base)+b·(model−base)+base`.
- per-term feature pins (shared-detection): `iso_dbl_bwd_counts`, `conn_rank_indexed`, `passed_three_state_path`, `mobility_histogram`, `ks_shield_open_file_features`, `outpost_rank_band_3_5`, `rook_file_open_vs_semi`.
- `accessor_dot_weights_equals_term_fn` — for each refactored eval term, `dot(accessor_features, eval::data weights) == <existing term fn>` (pins the refactor; bench byte-check is the global guard).

**`params.rs`:**
- `shipped_params_match_data_consts` (single-source-of-truth pin; a const edit fails it).
- `conn_is_live_other_core_groups_zero_at_shipped` (the CONN asymmetry, explicit).
- `core_vec_roundtrip`, `params_json_roundtrip`, `read_params_file_rejects_schema_mismatch`.
- `core_index_map_covers_all_core_no_overlap`; `excluded_and_outer_params_not_in_core_vec`.
- `apply_rewrites_marked_regions_only` (incl. CONN region; PST/frozen blocks byte-identical; **idempotent**).
- `apply_then_reparse_matches_tuned_model` (golden, unit-level: re-parsed consts reproduce the model).

**`loss.rs`:**
- `closed_form_gradient_matches_finite_difference` (analytic vs central-diff, all groups — the gradient gate).
- `l2_and_monotonicity_gradients_match_finite_difference` (init = shipped core).
- `loss_matches_objective_logistic_loss_at_integer_scores`.

**`optimizer.rs`:**
- `adam_recovers_known_optimum_on_synthetic_linear`.
- `coord_descent_agrees_with_adam_small`.
- `early_stop_restores_best_not_last`; `quantization_floor_halts_when_int_weights_stable` (tested at a rounding boundary).
- `checkpoint_roundtrip_bit_identical`; `resume_equals_uninterrupted` (N == N/2+save+load+N/2: params/moments/rng/k identical).

**`dataset.rs`:**

- `split_by_game_no_leakage` (no `game_id` on both sides); `split_deterministic_under_seed`; `split_changes_with_seed`.
- `mixture_reweight_changes_effective_source_counts`.

**`mixture.rs`:** `simplex_selects_on_held_out_objective`; `simplex_improves_or_ties_uniform_on_synthetic`.

**`tests/texel_resume.rs`** (integration, mirrors `tests/corpus_reproducibility.rs`):

- `resume_ignores_torn_temp_checkpoint` — inject a partial temp file (kill between fsync and rename) → prior checkpoint used (mirrors `store.rs` torn-tail discipline; directed, not random).

## Order of operations

1. `eval/data.rs` markers (comment-only); the read-only `pub(crate)` accessors in mobility/king_safety/tier1/pawns (refactor scoring fns to `dot(features, weights)`); `cargo test` + bench byte-check to confirm neutrality; Cargo deps + `pub mod texel` + bin registration; `cargo deny`/`audit` on the dep change.
2. `layout` + `params.rs` (index map + `EvalParams` + `shipped()` + vec/json/apply) — shared contract.
3. `features.rs` (`reference_score_white` + fast model + three-tier cross-check) — **Opus slice**.
4. `dataset.rs` (lane load + cache + split + mix).
5. `loss.rs` (gradient + reg) — **Opus slice**.
6. `optimizer.rs` (Adam + checkpoint/resume + coord-descent check).
7. `mixture.rs` (optional) + `bin/texel-tune.rs` + `apply` + sensitivity.
8. Tests pass → pre-review checks → final review.
   - **K-fit cadence (default `tune` path):** fit K **once** via `fit_k_features` on the `init` (shipped) weights *before* the Adam solve; freeze K for all Adam iterations (never refit inside the loop — research §2). Refit only per mixture candidate (the optional `mixture` path) or on corpus change.
9. In-session full tune on the 8M corpus → `bench/m6-params.json` → `apply` to a scratch `data.rs` copy + golden → confirm engine bench byte-identical (harness landing inert).
10. Commit harness + params.json + re-run script. Surface the operator SPRT step.

## Parallelization map

- **Sequential foundation (two layers):** step 1 (eval accessors — the second shared
  contract the v1 plan omitted) → step 2 (`layout`+`params.rs`) → step 3 (`features.rs`,
  Opus, depends on both). These cannot parallelize — they are the shared contract.
- **Parallel after the foundation** (file-disjoint): Slice C `dataset.rs`; Slice D
  `loss.rs`+`optimizer.rs` (Opus — gradient/Adam/resume invariants); Slice E
  `mixture.rs`+`bin`+`apply`+`sensitivity`.
- Test-writing per module drafts in parallel against the pinned signatures, test-suite-reviewed together before implementation.
- Conflict risk = only the shared `layout`/`params.rs`/accessor contracts, pinned up front.

## Dependencies

- Reuses `corpus::store::scan_valid_blocks`, `corpus::manifest::read_manifest`,
  `corpus::quiet::static_eval_white`, `corpus::objective::{fit_k, logistic_loss, stratified_objective}`,
  `corpus::prng::Prng`, `Position::from_fen`. New deps: `serde`+`serde_json` (general-purpose;
  `cargo deny`/`audit` after the Cargo change).
- **Provenance:** `tune` records the consumed `lane_sha256` in `ParamsFile`; `apply` and
  `re-run.sh` cross-check them against the on-disk lanes + `filter_spec.txt` pinned constants
  (M6.G discipline) so a regenerated corpus can't be silently mis-attributed.
- **Risks (ADR-0037 Consequences):** king-safety S-curve excluded (deferred, documented);
  feature-model faithfulness (mitigated by the three-tier cross-check that validates in the
  tuned regime); scale coarse-swept only.
