## What landed

Two independent things, both required for the candidate weights to be a
meaningful test:

1. **Full Nelder–Mead meta-tuner** in `src/texel/mixture.rs` (commit `b1c4b74`,
   already on `main` and CI-green at landing). Replaces the M6.I "coarse
   Nelder–Mead-style" reflect-only simplex with the full algorithm (reflect /
   expand / contract / shrink, standard α=1 / γ=2 / β=0.5 / σ=0.5), searches
   in R³ z-space via softmax with `z₄ ≡ 0` anchor (replaces `clamp +
   renormalize` on the 4-D mix), seed simplex is four asymmetric lane-dominant
   vertices mapping to mixes 3:1:1:1 / 1:3:1:1 / 1:1:3:1 / 1:1:1:3 (uniform is
   no longer a seed; it is the centroid, naturally reachable via
   contraction), and Kelley's sufficient-decrease restart (1999) guards the
   McKinnon-1998 degeneracy failure mode. Checkpoint format bumped `MIX1 →
   MIX2`. 13 new mixture tests cover softmax stability, seed simplex
   full-rank-in-R³, each move's textbook arithmetic, end-to-end search prefers
   lane 0 above uniform on the lane-0-favored synthetic, MIX2 bit-exact
   roundtrip + resume + stale-config rejection. Reviewer approved blind. ADR-0037
   stands (§8 mixture path; the new algorithmic specifics are tactical updates
   within that decision, not architectural revisions).

2. **Cold-start corpus-mixture retune** (this commit). One-off in-binary
   `EvalParams::shipped().with_core(&vec![0.0; N_CORE])` cold-start init
   (uncommitted to source — the binary was built with the override, then the
   source reverted; the run only requires the binary in `target/release/`),
   on the live 16M-position M6.H2 corpus (the same `bench/corpus/{onbook,
   offbook, ccrl, lichess}/lane.bin` lanes as M6.I), `--seed 20260524
   --max-iter 1000 --eval-every 25 --patience 8`. Background-QoS / `nice 19`
   over 4 h 41 m (including a sleep window). **Terminated at outer iter 8/30
   via `obj_spread < EPS_F = 1e-6`** — the convergence stopping condition the
   full N-M added. Chose mix
   `[0.3208, 0.1477, 0.2259, 0.3056]` (onbook 32 % / offbook 15 % / ccrl 23 %
   / lichess 31 %) at **val_loss 0.142749**, K = 0.005690. `texel-tune apply`
   → `src/eval/data.rs` rewrites the `TEXEL-TUNABLE` regions; new bench
   `1357063` / d4 `112497` (vs M6.I's `1411314` / `111498`).

## Why the rewrite — the M6.I reflect-only stall

The post-M6.I meta-tune post-mortem ([`meta-tune-postmortem.md`](meta-tune-postmortem.md))
captured the surface findings: a 9 h aborted run hit a per-epoch cache
re-streaming bug (fixed in `eff279a`) and lacked observability + checkpointing
(both fixed before that ship). The post-mortem's "uniform mix wins" verdict —
recorded as the run's only signal — was reproduced cleanly in a follow-up
~96-min cold-start re-run (perf fix in place; bench `bench/m6i-meta-params.reflectonly.json`).
That re-run *also* converged on uniform.

The N-M behaviour on that re-run is what motivated this rewrite: after the
5 seed vertices, every reflection was rejected, the simplex was unchanged
under the reflect-only rule, and the *same* `[0.333, 0.333, 0.333, 0]`
vertex was recomputed 12 times. Half the compute budget produced zero new
evaluations. The "uniform wins" verdict was *the search not exploring*, not
the corpus genuinely preferring uniform. The reflect-only rule has no escape
from this state — any time the reflection lands worse than the worst, the
simplex never moves and the next iteration recomputes the same number.

The full N-M's contraction moves are precisely the escape. The cold-start
re-run with the rewrite saw **all four move types fire** (reflect, expand
[failed back to reflect], outside-contract and inside-contract both
accepted) — and found a genuinely non-uniform optimum
`[0.32, 0.15, 0.23, 0.31]` at val_loss 0.142749, 2 µ-loss below the
reflect-only uniform's 0.142751. The two points sit in a flat valley; the
old search couldn't traverse it.

## Design (ADR-0037 §8, tactical updates)

- **Softmax reparameterization** (z ∈ R³ with `z₄ ≡ 0`; `p_i = exp(z_i) / Σ
  exp(z_j)`). Removes the `clamp + renormalize` discontinuity right where
  N-M most often probes, and matches the 3-simplex's intrinsic dimension —
  N-M operates on full-rank R³ with no constraints. Softmax over the
  alternative (sigmoid + renorm) avoids saturation-flatness: when `|z_i|` is
  large, sigmoid saturates and after renormalize, large z perturbations
  produce vanishingly small p perturbations; softmax doesn't double-nonlinearize.

- **Seed simplex** — four z-triples `[ln 3, 0, 0]`, `[0, ln 3, 0]`,
  `[0, 0, ln 3]`, `[−ln 3, −ln 3, −ln 3]` mapping to mixes 3:1:1:1, 1:3:1:1,
  1:1:3:1, 1:1:1:3. Each pushes one lane toward dominance. Uniform mix is no
  longer a seed vertex (it is the centroid of these four in mix-space,
  naturally reachable via contraction). The reflect-only simplex's
  "structural floor of ≤ uniform" guarantee is replaced by an *active*
  search that may dip below it — the lane-0-prefers-strictly-above-uniform
  synthetic test pins this empirically.

- **All four N-M moves** (textbook coefficients α=1, γ=2, β=0.5, σ=0.5).
  Reflect first; expand if reflection is new best; outside contract if
  reflection beat the worst (the simplex overshot but direction was right);
  inside contract if reflection didn't beat the worst (direction itself was
  wrong); shrink as fallback if contraction also fails. Acceptance is
  strict-`<` on both outside and inside contraction — a tie with the
  acceptance threshold falls through to shrink, a slightly more cautious
  variant of the textbook rule.

- **Kelley's sufficient-decrease restart** (1999). If over a sliding
  `KELLEY_WINDOW = 5` of completed iterations the best vertex's objective
  has not decreased by at least `KELLEY_TAU · z_spread²`, the simplex is
  replaced with a fresh axis-aligned simplex around the current best.
  Capped at `MAX_RESTARTS = 2` to bound runtime. Guards the McKinnon-1998
  degeneracy failure mode (repeated contractions driving the simplex into a
  lower-dim subspace where it cannot recover).

- **Stopping conditions** — first of: objective spread `max(f) − min(f) <
  EPS_F = 1e-6`, z-space parameter spread `max ‖z − centroid‖ < EPS_Z =
  0.005`, or `NM_MAX_ITER = 30` iterations. The cold-start campaign
  terminated at iter 8 via the objective-spread tolerance — algorithmic
  evidence the simplex found a local optimum, not the iteration cap.

- **Returns the best vertex**, not the centroid — we already paid to
  evaluate it; the centroid is an unevaluated interpolation that would need
  an extra inner solve and is no safer than a real measurement.

- **Checkpoint format `MIX2`** with per-iteration granularity and bit-exact
  resume via `to_bits` encoding. A kill mid-iteration loses at most one
  outer N-M iteration's worth of inner tunes (1–4 depending on which moves
  fired). JSON float serialization is non-bit-exact (≤1 ULP drift); the
  binary codec mirrors `optimizer::save_checkpoint`'s discipline. `MIX1`
  checkpoints are rejected by magic check on resume.

    R3 design comment), so this is a no-op there — pure correctness
    hardening triggered by an eval shift the test was brittle to.
- `cargo clippy --all-targets -- -D warnings` clean; `cargo fmt --check`
  clean; `cargo test --doc` clean.

#### Why LLR didn't cross at 400 games even though the CI clearly did

The GSPRT log-likelihood ratio is sensitive to the *evidence rate*, not
just the point estimate. With a 54 % draw fraction in this matched-eval
gate (clawfish-vs-clawfish), each pair contributes proportionally less
LLR signal than in a Stockfish-asymmetry rating-estimate. The pentanomial
Wilson CI converged on a clean +41 [+18, +64] interval (lower bound 3.6×
the elo1=5 threshold) well before LLR crossed ±2.94. The verdict ladder's
CI-based rungs (ADR-0037 §9) are the disposition rule for exactly this
case — the cap-hit-with-clean-positive-CI outcome is **rung 1**, not a
fourth "inconclusive" rung — and the disposition is **ship**.

`docs/workflow.md` §"Chaining unattended step-12 gates" captures the
process lesson the agent took from this run: log-content Monitors must
enumerate every terminal state (the agent's `verdict=H[01]` filter missed
the `verdict=continue` cap-hit line and left the next gates unstarted for
~7 h until the operator asked).

### Prior vs outcome

Prior (recorded ahead of SPRT): val_loss delta vs the reflect-only run was
2 µ-loss (0.142751 → 0.142749), "well below where I'd predict a detectable
Elo gain at a practical SPRT budget." The prior was **wrong**: the cold-
start retune produced a meaningfully different weight vector (not just a
tweaked one) on a different mix, and the resulting +41 Elo is well outside
the noise floor at 400 games. The lesson is that **val_loss is a poor
single-figure proxy for Elo when the parameterization changes** — two
weight vectors at indistinguishable val_loss can play very differently if
they sit in different basins of the eval surface. The corpus-fit metric is
linear-loss on quiet positions; the SPRT measures the integrated
search-and-play behaviour, which is sensitive to non-linearities (qsearch,
move ordering, history-based pruning, TT) the corpus fit doesn't see.

## Lessons

- **Reflect-only N-M is structurally unsound on flat surfaces.** When the
  reflection is rejected, the simplex is unchanged and the next iteration
  recomputes the same number — a deterministic infinite loop of pure noise.
  The textbook full N-M's contraction moves are precisely the escape; a
  meta-search that's "good enough most of the time" but has this regime
  failure mode is a hidden tax that goes unnoticed until a different eval
  landscape exposes it.

- **The probability simplex is *not* the right search space for N-M.** The
  bounded constraint surface forces a `clamp + renormalize` projection
  which is a discontinuity right where N-M most often probes
  (reflected/contracted points that would land outside the simplex). The
  sum-to-1 constraint also makes the search rank-deficient by one
  dimension. Both vanish under the softmax reparameterization into R³ —
  N-M then operates on full-rank, unconstrained, smooth space, dimensionally
  honest about the 3-simplex.

- **The "uniform wins" conclusion from a stalled search is
  indistinguishable from a real preference for uniform in the data.** Only
  the full N-M's distinct evaluations across the simplex (no redundant
  recomputes) actually decides which it is. On this corpus, with this base
  eval, the answer is "uniform doesn't dominate; there's a non-uniform
  point in the same flat valley." Whether that translates to Elo is the
  SPRT.

- **`play_one_game`'s `&mut` searcher API was an under-specified contract.**
  The test pinning warm-vs-cold equivalence passed at M6.I because the
  leftover TT / history / killers / pawn-hash state didn't materially shift
  search outcomes at that eval landscape and that specific seed. M6.J's
  weights broke the lucky alignment. The principled fix is to make the
  contract honest — fresh searchers at the top of `play_one_game` — rather
  than to retune the test fixture to a different seed (the M6.I KPK →
  Kiwipete fixture-fragility precedent, which addressed a symptom rather
  than a contract). This was a latent R3 risk in selfplay code paths that
  reused searchers across games; production `selfplay::run` already used
  fresh searchers, so no historical corpus production was affected — but
  the test failure was a useful signal.
