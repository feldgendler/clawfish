# M5.K — Adaptive aspiration window (delta-baseline), default ON

**Shipped 2026-06-06** (commit `55c8fae`). Production HEAD = `M6.J` (eval) + `M5.K` (search).
**Bench:** d4 `112020` (unchanged — aspiration fires only at depth ≥6) / d7 `1326598`
(was `1354640` under fixed-±50; node savings from tighter first-try windows on stable
positions). **Eval untouched** — pure search-layer change.

## What shipped

`Aspiration_Adaptive` flipped from OFF (fixed-±50) to **ON by default**. The first-try
aspiration half-width is now volatility-responsive:

```
half = clamp((K·|score(d-1) − score(d-2)| + 50) / 100, MIN, MAX)   // K=2.00, MIN=25, MAX=250
     = 50 (fixed)                                                  // when score(d-2) unavailable,
                                                                   //   or depth outside band [6,64]
```

It *widens* the window on volatile positions (large inter-iteration score swing) and
*narrows* on stable ones, betting on score continuity to save re-searches. Five runtime
UCI options expose the mechanism: `Aspiration_Adaptive` (now `default true`),
`Aspiration_K` (centi-K, 200), `Aspiration_Min` (25), `Aspiration_Max` (250),
`Aspiration_AdaptiveMinDepth` (6), `Aspiration_AdaptiveMaxDepth` (64). The fixed-±50 OFF
path remains reachable via `setoption Aspiration_Adaptive value false` for diagnostics.

## Strength

**SPRT vs `M5.F.1`** (same-binary self-SPRT — candidate = adaptive ON, baseline = adaptive
OFF; one binary both sides, zero toolchain confound), mixed-TC + virtual-clock, elo0=0
elo1=10:

- **Δ Elo +13.03 [−3.78, +29.91]**, 2-seed-confirmed (item5, 2026-06-03: seed1 +20, seed2 +6).
- **rung-2 "ship-with-note"** per the ADR-0037 ladder: mean +13 ≥ 5 and CI-lower −3.78 > −10.
  Strict CI-lower>0 not met → user-approved judgment ship, not an automatic CI ship.
- Per-TC: the gain concentrates at the mid TCs (**20+0.2 +23/+20**) where clawfish's
  depth-reach (~11.5) makes the |Δscore| volatility signal informative; flat-to-slightly-
  negative at the extremes (10+0.1 too shallow for a stable delta; 60+0.6 deep enough that
  fixed-±50 already suffices). Coherent mechanism story.

## Why this is the ceiling — two failed improvement levers

M5.K ships the **ungated** mechanism because both attempts to improve on it failed:

1. **SPSA-tune K/MIN/MAX (lever 2) — ruled out low-signal (2026-06-06).** Built the SPSA
   harness (`docs/plans/spsa-harness.md`, Unit 1 `fd1be1a` + Unit 2 `9d734d9`), then a
   shakedown + a 3×-`c_end` calibration showed the per-iteration `match` score is mostly
   draws / sign-unstable noise: aspiration is a node-*efficiency* knob, not a move-*quality*
   knob, so game outcomes carry almost no gradient about K/MIN/MAX. Extracting the sub-Elo
   gradient would need ~20k iterations (~15–30h) for a ~+13 ceiling — a poor compute trade.
   The harness is a sound, reusable deliverable for higher-signal future targets.
2. **Depth-gate the adaptive width (lever 1) — REFUTED (2026-06-06, `b03c942`).** Hypothesis:
   confine adaptation to a mid-depth band `[8,12]`, fixed-±50 at shallow/deep, to keep the
   20+0.2 win without the extreme-bucket drag. SPRT'd **−34.9 Elo over 800 games** (2 seeds,
   both CIs fully negative). The regression landed in **exactly the 20+0.2 bucket the band
   was meant to protect** — gating did not "keep the good part," it broke the mechanism
   (likely a band-edge discontinuity at the mid-TC median depth ~11.5 ≈ band-max 12, flipping
   consecutive first-try windows between adaptive and fixed). The depth-gate code is kept as
   an inert default-OFF runtime feature (`Aspiration_AdaptiveMin/MaxDepth`, default band
   `[6,64]` = no-gate). **Lesson: the adaptive-width benefit is not cleanly depth-localizable.**

## Engineering notes

- **"Default = production = adaptive ON":** `AspirationParams::default()` now yields
  `adaptive=true`, so `bench` (which runs through the mover's params) reflects production.
  OFF-path unit tests construct an explicit `AspirationParams { adaptive: false, .. }` — no
  assertion was weakened in the flip; the fixed-±50 numbers are pinned by explicit-OFF tests.
- **Verification:** 1994 lib tests green; build/fmt/clippy clean; `cargo mutants` on the band
  gate 19/19 caught; the underlying logic carried a blind final-review APPROVE at `89e4dad`.
- **Self-SPRT methodology:** one binary both sides (options-only differential) is strictly
  cleaner than the historical patch-binary-vs-tag flow — it removes any compiler/toolchain
  drift between candidate and baseline. Runner: `scripts/sprt-depth-gate.sh`.
