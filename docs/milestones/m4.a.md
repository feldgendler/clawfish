# M4.A — Transposition table

Status: complete (2026-04-29). First M4 phase. Adds (a) a Zobrist-keyed transposition table layered over M3.E's iterative-deepening alpha-beta, with depth-preferred + age-bias replacement; (b) bound-aware probe with cutoffs at non-PV nodes only; (c) mate-score depth-adjustment on store/probe; (d) the `Hash` UCI option (default 16 MiB, range 1–4096); (e) `Engine::reset_for_new_game()` as the single source of truth for game-boundary lifecycle, called from `handle_ucinewgame` and per-bench-position; (f) `prior_root_move` removed — the TT subsumes its M3.E role.

`bench` from production binary at default depth 7: **`bench: 39964046 nodes <NPS> nps`**. Down from M3.F's 172,312,700 nodes — **77% reduction** from TT participation. NPS varies wallclock-to-wallclock and is excluded from the regression signature.

ADR-0018 binds the TT layout, replacement scheme, mate-score discipline, GHI stance, and bench-reset inventory. ADR-0017's `prior_root_move` plumbing is superseded; `compute_caps`, the ID outer loop, and the soft/hard cap discipline are unchanged.

## What landed

**`src/tt.rs` — new module:**

- `pub(crate) enum TtBound { Exact, Lower, Upper }` with `#[repr(u8)]`.
- `pub(crate) struct TtEntry` (16 bytes): `key: u64`, `score: i16`, `depth: u8`, `age_and_bound: u8` (6 bits age + 2 bits bound), `best_move: u16`, `_pad: u16`.
- `pub(crate) struct TtData` — input bundle to `store`.
- `pub(crate) struct TranspositionTable` with `UnsafeCell<Vec<TtEntry>>` + `AtomicUsize` mask + `AtomicU8` generation.
- `unsafe impl Sync for TranspositionTable {}` with SAFETY comment citing ADR-0011 + ADR-0018 §2.
- `score_to_tt(score: i32, ply: i32) -> i32` and `score_from_tt(score: i32, ply: i32) -> i32` pure helpers (mate-aware, threshold `MATE_IN_MAX_PLY = 29936`).
- 23 unit tests pinning entry pack/unpack, replacement scheme, generation wraparound, mate-score round-trip (proptest), and entry size.

**`src/search.rs` — restructure:**

- `AlphaBetaMover.prior_root_move` field REMOVED. Three obsolete tests deleted; replaced with TT-based S7 (`negamax_id_iteration_uses_prior_iteration_tt_move_at_root`).
- `AlphaBetaMover.tt: Option<Arc<TranspositionTable>>` field added; populated from `ctx.tt` at top of `Search::go`; cleared between searches.
- `SearchContext.tt: Option<Arc<TranspositionTable>>` field added.
- `negamax` signature gains `is_pv: bool`. Body restructured per ADR-0018 §13: clear PV → qsearch-on-horizon → nodes/cancel → capture `original_alpha` → rep/50-move → MDP → TT probe (cutoff at non-PV, ordering at PV) → moves + searchmoves → terminal → MVV-LVA + TT-move-first reorder → recurse with `child_is_pv = is_pv && i == 0` → store on completion (gated by `!self.aborted`).
- `Search::go` calls `tt.new_search()` once per `go` to advance the generation counter.
- 15 new tests (S1–S13 + S3b + S4b) pinning TT integration semantics: store on completion, no mid-loop store, no store on abort, non-PV cutoffs (Lower + Upper), PV-node cutoff suppression, TT-move-first ordering, mate-score round-trip across plies, repetition before TT probe, 50-move before TT probe, TT clear invalidates cutoffs, collision-garbage rejection, is_pv recursion-order plumbing.

**`src/engine.rs` — wiring:**

- `Engine.tt: Arc<TranspositionTable>` and `Engine.hash_mib: usize` fields added.
- `Engine::new` constructs the TT internally with `DEFAULT_HASH_MIB = 16`.
- `handle_uci` emits `option name Hash type spin default 16 min 1 max 4096`.
- `handle_setoption` adds case-insensitive `hash` parsing; on valid `[1, 4096]`, joins in-flight worker, resizes TT, clears `stop`. Out-of-range silently rejected (`info_string_debug` echo).
- `Engine::reset_for_new_game()` private helper: joins worker, resets position to startpos, resets game_history, clears TT (also resets generation to 0), calls `Search::reset`. Called from `handle_ucinewgame` and per-position from `handle_bench`.
- `handle_go` and `handle_bench` populate `SearchContext.tt = Some(Arc::clone(&self.tt))`.
- 7 new tests (E_a–E_f + E_b2) pinning option emission, resize-both-directions, ucinewgame TT clear, bench TT determinism, stop-clear-after-resize.

## Plumbing / process highlights

**Plan-review converged in pass 2.** Pass 1 raised 4 must-fix items (mate-score type ambiguity, `is_pv` recursion-index discipline, `original_alpha` capture-before-MDP, abort-skip + end-of-loop-only store invariants) + 12 should-fix; all addressed in v2. Pass 2: no must-fix remaining; loop terminated.

**Coder slicing per plan §6 worked cleanly.** Slice A (Sonnet) shipped `src/tt.rs` self-contained with 23 tests; Slice B (Opus, flagged for novel-invariant + cross-call-site discipline) shipped the negamax restructure + 15 search tests; Slice C (Sonnet) wired the engine + 7 tests.

**`prior_root_move` removal flagged 3 obsolete tests for explicit deletion.** Plan §3.5 enumerated the test surface (grep + line numbers) so Slice B's coder didn't have to discover ad-hoc.

**Bench signature changed by design.** TT participation cuts the search tree by ~77% at default depth 7 (172M → 40M nodes). NPS dropped because TT probe/store add per-node overhead; the wallclock-relevant figure is the SPRT result.

**Plan-review caught the `Mutex<Vec<TtEntry>>` perf trap pre-implementation.** Initial draft used `Mutex` for safety; pass-1 reviewer flagged ~23% CPU overhead at 11.5 Mnps × 23M lock acquisitions/sec. Revised to `UnsafeCell<Vec<TtEntry>>` + `unsafe impl Sync` with single-mutator discipline anchored to ADR-0011's threading model. Avoided shipping a known-suboptimal scheme.

**`prior_root_move` fate option (1) "Remove" chosen** vs (2) "keep as fallback" or (3) "always-populated mirror." Roadmap-tentative was option (3); plan §0 reasoned through M4.D aspiration-window edge cases and concluded option (1) is sound under the M4.A replacement scheme + abort-skip + end-of-loop-only store discipline. Pinned by S3 + S3b.
