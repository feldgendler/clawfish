## What landed

PVS (M8.A, ADR-0043) gated by a smooth root-depth ramp. A non-first move at
move-ordering rank `cur_i` is scouted (PVS three-step ladder) iff
`cur_i >= pvs_scout_start(root_depth)`; otherwise it takes the pre-PVS reference
full-window LMR path. The ramp (`PVS_RAMP_{D0=12, BASE=16, SLOPE=4}`):

```
pvs_scout_start(d) = MAX            for d <= 12   (no scout ⇒ reference path ⇒ ≡ M7.B.2)
                   = 16 - 4*(d-12)  for 13..15    (d13→12, d14→8, d15→4)
                   = 1              for d >= 16    (full PVS ≡ M8.A)
```

`root_depth` is the ID iteration depth (ADR-0041, constant across the negamax tree),
so the conditioning is on the *deciding* iteration's depth — the same lever M7.B.2 used.

## Why it was needed

M8.A (unconditioned PVS) was **net ≈ −20 Elo, depth-amplifying**: the Step-3 full-window
re-search flips `is_pv` false→true and suppresses NMP/RFP/FFP/LMR in that subtree — a cost
with no depth headroom at fast TC (10+0.1 −45 / 20+0.2 −25 / 40+0.4 −20) but a net win at
slow TC (60+0.6 +73). The mirror image of M7.B's profile. M8.A.1 suppresses the scout at
the shallow root iterations a fast TC completes and engages it at the deep iterations a slow
TC reaches.

## Engineering notes

- **Off-regime byte-identity to `M7.B.2` is the safety mechanism** and held: bench d4
  `45788` / d7 `662085` unchanged (ramp inert at bench depth ≤ 7 ≤ D0). The integration
  bench-signature pin was re-pinned 47763 (M8.A) → 45788 (the intended revert; a mismatch
  is stop-the-line, not a re-record). Final review confirmed the identity *structurally*:
  LMR is `!is_pv`-gated, so at a PV node `r=0` and the reference path searches once at
  `pv_scout_child=false` = M7.B.2's non-first-move PV-ness.
- The reference full-window path (previously test-only behind `test_disable_scout`) is now
  production-active for non-scouted moves; it gained the ladder's `#[cfg(test)]` LMR counter
  instrumentation (scalars + move vectors, trace-ply-gated) so the existing LMR-firing tests
  stay valid with `root_depth` unset.
- Test harness gained `negamax_at_root_depth_for_test` (mirror of
  `qsearch_at_root_depth_for_test`) so PVS tests exercise the scout at `root_depth >= 16`;
  paired exactness tests run **both** arms at the same root_depth to isolate the PVS delta
  from the M7.B.2 qsearch ramp (which `root_depth > 12` also drives).
- Gate: lib 2098/0, integration green, clippy/fmt clean, llvm-cov search.rs 97.94%/98.22%,
  `cargo mutants --in-diff` 0-missed (15 caught / 4 timeout / 1 unviable), three blind-review
  loops converged.

## Lesson reinforced

This is M7.B → M7.B.2 applied in the mirror direction, and it honors the **M5.K caution**
(depth-*band* on aspiration width backfired −34.9 Elo, "the adaptive benefit is not cleanly
depth-localizable"): M8.A.1 uses a **monotonic, smooth** ramp (no band, no single-ply cliff)
whose off-regime is the proven-safe baseline. Depth-conditioning works when the off-regime is
byte-identical to a known-good baseline and the transition is smooth.
