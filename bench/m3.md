# M3 — Alpha-beta + material eval

Per ADR-0010 milestone-summary format. Per-phase entries; final summary lands when M3 closes.

## M3.A (2026-04-28) — material + PST eval + GreedyMover

First playing-engine phase: depth-1 best-eval with reservoir-sampled tie-break replaces M2.E's RandomMover as production search. PeSTO middlegame material + PST tables vendored verbatim. Incremental `static_eval_white` field on `Position` maintained through `make_move`/`unmake_move`. Insufficient-material draw detection in eval (KvK / KvN / KvB).

ADR-0014 codifies eval composition. No microbenchmark — UCI dispatch + depth-1 single-pass evaluate are not search-hot-path; M3.C alpha-beta will be the first phase with a meaningful nps figure.

### Qualitative behavior shift from M2.E

| Feature | M2.E (RandomMover) | M3.A (GreedyMover) |
|---|---|---|
| Move pick | Uniform random | Depth-1 max(`-evaluate(post_make)`); reservoir-sampled tie-break |
| `info` line score | Always `cp 0` (placeholder) | Real centipawn eval |
| Self-play termination | 343 / 450 ply (random shuffles → KvK / KvN insufficient-material draws) | 20 / 20 ply (one side blunders material in opening; resign-threshold adjudication fires) |
| Captures | Accidental | Greedy (always takes the highest-value capture available at depth 1) |
| Stockfish-1320 outcome | sf18 mates within 25–56 ply | sf18 mates / adjudicates within 37–41 ply |

### Plumbing / process highlights

- **Three review loops** all converged: plan-review (3 passes; 6 must-fix → addressed), test-suite review (2 passes; 2 must-fix → addressed), final-review (3 passes; 1 must-fix → addressed via split-file refactor for cargo-mutants exclusion).
- **PeSTO data isolation.** `src/eval/data.rs` houses the vendored MATERIAL + six MG_*_PST arrays; `src/eval.rs` houses the logic (PSQT compile-time builder, `evaluate`, `eval_white_from_scratch`, all tests). File-level `cargo mutants` exclusion matches the `src/magic/constants.rs` precedent verbatim.
- **No new ADR beyond ADR-0014.** ADR-0011 (UCI threading) unchanged; ADR-0007 (legal-direct movegen) consumed via `generate_moves`; ADR-0004 (NNUE hooks) extended naturally — the new incremental-static-eval delta is the same shape as the future NNUE accumulator.
- **`baseline/material-greedy` annotated tag** lands at the M3.A commit per `docs/workflow.md` SPRT methodology — the reference point for any future SPRT match against M3.A's "depth-1 greedy" behavior (just as `baseline/random-mover` from M2.E is the reference for "uniform random").
