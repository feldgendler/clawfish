# 2026-05-08 — M5.E Stockfish UCI_LimitStrength rating estimate

Cross-engine rating estimate for the M5.E build (qsearch correctness) against Stockfish anchored at the M5.D-v2 estimate (`UCI_Elo=2641`). Mixed-TC, frozen-K (`--k0 0 --target-sigma 0`), 200 games / 100 pairs.

## Run shape

- **Date**: 2026-05-08, ~09:01 → ~10:30 local (Apple M4, dev machine; concurrency 4 + `taskpolicy -c utility`).
- **Configuration**: `STOCKFISH_ELO=2641 SPRT_TC_SAMPLE="10+0.1:1,20+0.2:1,40+0.4:1,60+0.6:1" SPRT_SEED=0xC1ABF15AE10DD009 SPRT_GAMES=200 SPRT_CONCURRENCY=4 scripts/sprt.sh rating-estimate`. Frozen-K + disabled-σ via `--k0 0 --target-sigma 0`.

## Interpretation

CI overlaps 0 — **statistically indistinguishable** from M5.D-v2's 2641 anchor. The point estimate's slight negative drift (~−19 Elo) is consistent with the parallel SPRT vs `M5.D` (which showed ~−15 Elo within CI [−36, +6]) and with M5.E's expected `<5 Elo` true signal. The cross-engine measurement noise is wider (per-TC variance is larger) than the within-engine SPRT, so the two CIs are mutually compatible.

**Per-TC pattern is not bimodal** unlike M5.D-v1's striking fast-vs-slow split. The 10+0.1 weakness (38%) is localized — 20+0.2 actually improved (57.5%); 60+0.6 is flat. Reading: random fluctuation at small per-TC sample sizes (40 games each). Not a regime-shift signal.

**Stockfish UCI_LimitStrength caveat (preserved from M5.D-v2)**: Stockfish's `UCI_Elo` calibration is anchored at slow TC (typically 60+0.6 or 120+1.2) per its own documentation. Running rating-estimate at 10+0.1 / 20+0.2 / 40+0.4 makes Stockfish move in less time than its calibration assumes, which can introduce per-TC variance that doesn't reflect clawfish's actual relative strength at those TCs. The aggregate score combined across the four TCs partially averages this out, but individual per-TC scores carry caveats.
