# 2026-05-09 — M5.F mixed-TC rating estimate vs Stockfish UCI_Elo=2641

Mixed-TC rating-estimate match against Stockfish 18 with `UCI_LimitStrength=true UCI_Elo=2641` (the M5.E anchor). Anchored measurement (frozen K + disabled σ-stop) intended to place M5.F on the same Stockfish UCI_Elo scale used for prior M5 phases.

## Run shape

- **Date**: 2026-05-09, ~11:54 → ~13:42 local (Apple M4, dev machine; concurrency 6 + `taskpolicy -c utility`).
- **Configuration**: `scripts/sprt.sh rating-estimate` with `SPRT_TC_SAMPLE="10+0.1:1,20+0.2:1,40+0.4:1,60+0.6:1"`, `SPRT_SEED=0xC1ABF15AE10DD00A`, `STOCKFISH_ELO=2641`, `SPRT_GAMES=200`. Frozen-K + disabled σ-stop (`--k0 0 --target-sigma 0`); 200-game cap.
- **Adjudication**: standard (resign-movecount=3 resign-score=600; draw-movenumber=34 draw-movecount=8 draw-score=20; max-moves=200).

- **Estimated clawfish rating**: 2641 + (−5.21) = **~2636 ± 43 Elo** (CI: [2593, 2678]).
- **Per-TC scores**:
  - 10+0.1: 53.7% (W=22 L=18 D=14; 54 games)
  - 20+0.2: 45.7% (W=16 L=20 D=10; 46 games)
  - 40+0.4: 46.3% (W=15 L=18 D=7; 40 games)
  - 60+0.6: 50.0% (W=20 L=20 D=20; 60 games)
- **Per-TC pattern**: closer to balanced than the in-engine SPRT (which showed a bimodal fast-positive / slow-marginal-negative pattern). The vs-Stockfish per-TC variance with smaller samples (40–60 games each) is not strong enough to separate from noise.
